# data

Everything that creates, validates, stores or moves data. Depends only on [`core/`](../core).

| File | Contents |
| --- | --- |
| [`storage.ts`](storage.ts) | **Only** access point to localStorage. Keys: `zennia:words` (`{ version: 2, words }`; version 1 files are still read, their words get no tags), `zennia:stats`, `zennia:kana-selection` and `zennia:words-focus`. Two private helpers hold the failure rules: `load` gives the fallback for anything missing, unreadable or invalid, and `save` ignores a full or blocked storage. Swapping for IndexedDB or a backend should touch only this file. |
| [`words.ts`](words.ts) | `sanitizeWords` validates any external data (localStorage or imported file; accepts an array or `{ words }`, discards items without `japanese`/`hiragana` (and, with `requireMeaning`, without a meaning: used by the JSON and Anki imports, while saved words keep an empty one), regenerates duplicate ids). `mergeWords` deduplicates by id or by `japanese\|hiragana`; a different meaning for an existing word is appended with `; `. `disabled` is always stored as a boolean and `tags` as a clean list (empty when missing); merging unites the tags of a word that already exists. Also the tag rules (`validateTag`, `cleanTags`, `sameTag`, `allTags`, `addTag`, `removeTag`, `renameTag`, `deleteTag`, `filterByTags`, `tagHue`) and the form rules (`needsMeaning`, `validateWord` (the meaning is required), `makeWord`, `updateWord`, `setDisabled` (enabling a word stamps `activatedAt`, which orders the status sort), which take the texts as typed), `searchWords`, `sortWords`, `importSummary` and `newId`. |
| [`stats.ts`](stats.ts) | Lifetime hit/miss tallies: `emptyStats`, `sanitizeStats`, `recordAnswer` (per word id), `recordKana` (per symbol via `kanaKey`), `drawWeight`/`pickWeighted` (the weighted random draw: weight from the miss rate plus a bonus for few answers, so missed and under-sampled items come up more often), and helpers (`accuracy`, `accuracyLevel`, `totalTally`, `percent`, `sortTallies`...). `almost` counts as a miss. |
| [`io.ts`](io.ts) | JSON export/import of the word list and of the stats (with a `version` for migrations), `exportFilename`, `statsExportFilename` and the browser download helper. |
| [`practice-session.ts`](practice-session.ts) | The flow both practices share, as pure functions on a `Session`: `startSession`, `nextRound` (weighted draw that skips the previous item), `submit` (check and score, or move on when a verdict is shown) and `resetScore`. A `PracticeMode` supplies what differs: pool, key, draw weight, check and record. |
| [`practice-modes.ts`](practice-modes.ts) | `wordsMode` (enabled words, by focus: reading, meaning or both; words that need a meaning are drawn only for the reading; `almost` is a real verdict, and with both it needs a correct meaning) with `checkParts` / `joinAnswers` and `kanaMode` (the selected symbols; `almost` becomes incorrect), the two `PracticeMode`s. |
| [`stats-rows.ts`](stats-rows.ts) | The rows of the Stats list: `buildRows` (words that were deleted are left out, their stats stay saved) and `filterRows` (kind, search, sort). |
| [`anki.ts`](anki.ts) | Imports an Anki "Notes in Plain Text" export (tab-separated, quoted multi-line HTML fields, front + back only). Reading = the back's headword with each `<ruby>` replaced by its `<rt>`; meaning = the first nested `<div>`. Cards whose reading isn't pure kana are skipped; repeated word + reading pairs are merged into one word, with different meanings joined by `; `. |
| [`strokes.ts`](strokes.ts) | `loadStrokes`: fetches `public/strokes.json` (stroke paths and number positions of kana and kanji from [KanjiVG](https://kanjivg.tagaini.net), CC BY-SA 3.0) the first time a writing sheet is opened. Regenerate the file with `node scripts/build-strokes.mjs <extracted kanjivg kanji dir>`. |
| `*.test.ts` | Tests for `words`, `stats`, `stats-rows`, `practice-session`, `practice-modes`, `storage`, `io` and `anki`. |

## Rules

- Components must not call `saveWords`/`saveStats` directly: `App.svelte` persists state automatically with an `$effect`.
- Stats are stored apart from the words and are **not** part of the JSON export.

# Glossary

| Term           | In the code                                                                                     | Meaning                                                                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Active word    | `disabled` is false (`Word`, `src/lib/core/types.ts`)                                           | A word practice can draw. A word that isn't active keeps its data and its tally.                                                                                                                                 |
| Almost         | `almost` (`Verdict`, `src/lib/core/types.ts`)                                                   | The verdict of a reading where only the vowel length differs. It counts as an error.                                                                                                                             |
| Dictionary     | `Dictionary` (`src/lib/data/dictionary.ts`)                                                     | The bundled JMdict common words, looked up by sound to fill in the words of a romaji list ("Add from romaji").                                                                                                   |
| Focus          | `WordsFocus` (`src/lib/data/practice-modes.ts`)                                                 | What practice asks for a word: its reading, its meaning or both.                                                                                                                                                 |
| Furigana       | `furigana`, `FuriganaPart` (`src/lib/core/furigana.ts`)                                         | The reading in hiragana shown above the kanji or katakana of a word, in the practice feedback. Hiragana runs (okurigana) get none.                                                                               |
| Kana selection | `kanaSelection` (`Settings`, `src/lib/data/settings.ts`)                                        | The kana practice can draw, chosen per script in the Kana tab.                                                                                                                                                   |
| Meaning        | `meaning` (`Word`)                                                                              | What the word means, free text. Practice can ask for it instead of, or along with, the reading.                                                                                                                  |
| New word       | `newWordIds`, `markSeen` (`App`, `src/lib/state.svelte.ts`)                                     | A word added since the app loaded, marked with a "new!" badge in the Vocabulary list.                                                                                                                            |
| Profile        | `Account` `name`, `avatarUrl` (`src/lib/data/db/client.ts`), `updateProfile` (`App`)            | The name and photo of a signed-in account, shown in the sidebar.                                                                                                                                                 |
| Reading        | `hiragana` (`Word`), `reading` (sort key and `WordsFocus`)                                      | How a word is pronounced, written in kana. It is typed and shown in romaji too, but romaji is not a separate field. Answers are checked against it.                                                              |
| System tag     | `SCRIPT_LABELS` (`src/lib/core/kana.ts`)                                                        | The built-in tag of a kana row in Stats, the name of its script (Hiragana or Katakana).                                                                                                                          |
| Tag            | `tags` (`Word`), `TagSearch` (`src/lib/components/TagSearch.svelte`)                            | A label on a word, to organize and filter the vocabulary.                                                                                                                                                        |
| Tally          | `Tally` (`src/lib/core/types.ts`)                                                               | The lifetime hits and misses of a word or kana.                                                                                                                                                                  |
| Vocabulary     | `/vocabulary`, `Manage` with `section="vocabulary"` (`src/lib/components/manage/Manage.svelte`) | The tab where the user adds, lists and tags their words and picks which ones are active in practice.                                                                                                             |
| Word           | `Word` (`src/lib/core/types.ts`); its written form is `japanese`                                | One entry of the vocabulary, with its reading, meaning and tags. "Word" is also the name of its written form (kanji or kana), the one shown in practice, which is `japanese` in the code and in the export file. |
| Writing sheet  | `sheetWords` (`App`), `PrintSheet` (`src/lib/components/print/PrintSheet.svelte`)               | The printable page for practicing writing the selected words by hand.                                                                                                                                            |
